# Чат-приложение на Qt (v0.2)

Простое чат-приложение с возможностью регистрации пользователей и обмена сообщениями.

## Особенности

* Регистрация и вход пользователей
* Обмен сообщениями в общем чате
* Приватные чаты между пользователями
* Сохранение истории сообщений в текстовых файлах
* Система модерации с командами администратора:
  * `/ban username time` - бан пользователя (time может быть: 1h, 1d, 1m, 1y, forever)
  * `/mute username time` - мут пользователя
  * `/warn username` - предупреждение пользователю
  * `/admin username` - назначение администратора
  * `/unban username` - разбан пользователя
  * `/unmute username` - размут пользователя
  * `/unwarn username` - сброс предупреждений
  * `/unadmin username` - снятие прав администратора
* Автоматическая загрузка приватных чатов при входе
* Автономная работа (все данные хранятся локально)
* Кроссплатформенность (Windows, macOS, Linux)

## Требования

* Qt 6.0 или выше
* C++17
* CMake 3.16 или выше

## Сборка

```bash
mkdir build
cd build
cmake ..
make
```

## Запуск

```bash
./bin/ChatApp
```

## Использование

1. Запустите приложение
2. Зарегистрируйте нового пользователя или войдите под существующим
3. Начните общение в общем чате или создайте приватный чат
4. Все сообщения сохраняются автоматически
5. Администраторы могут использовать команды модерации
